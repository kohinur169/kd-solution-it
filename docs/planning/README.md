# Historical Planning Records

Files in this directory preserve project history, decisions, audits and completed-step
breakdowns. They remain available as background and evidence for existing handoffs.

They are not active implementation instructions and do not define current product scope.
For current scope, coding rules and step order, use only the corresponding documents in
`docs/final/`.

When a historical document conflicts with `docs/final/`, the current `docs/final/`
documents take precedence. Consult historical records only when a current handoff or
specific implementation question requires their context.
